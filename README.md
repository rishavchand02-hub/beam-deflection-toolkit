
Toolkit

This is a small Python project I developed to practise Python programming using a basic engineering application. It calculates beam deflection for different beam types and loading conditions.

Files:

- main.py - Runs the calculations and handles the input and output files.
- beams.py - Contains the functions used to calculate beam deflection.
- config.json - Stores the material properties, spans, loads, and beam cases.
- results.csv - Contains the calculated results generated by the program.



Process:

1. Download the project.
2. Open a terminal in the project folder.
3. Run the following command:
Inside the terminal, type python main.py

4. The program calculates the deflection for the configured cases and saves the results in 'results.csv'.

  Inside the terminal, type the command
   python main.py

4. View the calculated results in 'results.csv'.

For Error Handling Tests

Test a missing configuration file:

python main.py missing.json

Test invalid JSON:


python main.py broken.json


Test invalid engineering input:

python main.py bad_values.json


Testing

I tested the program with a missing configuration file, invalid JSON, and a negative Young's modulus to check its error handling. I also included checks against standard beam deflection formulas.
